High School Track

Building the foundation for future innovators

Designed specifically for high school students (grades 9-12), this track focuses on fundamental programming concepts, creative problem-solving, and introducing students to the exciting world of technology and innovation.

Track Overview

The High School Track is designed to inspire and educate the next generation of technologists. With a focus on accessibility and learning, this track provides an excellent introduction to competitive programming and data science.

Beginner Friendly

Dataset & Challenge

Smart City Traffic Prediction Challenge

Challenge Overview

Welcome to the Smart City Traffic Prediction Challenge! Your task is to develop a machine learning model that can predict traffic congestion levels in urban areas using historical traffic data, weather conditions, and city events.

Goals

  • Predict traffic congestion levels for the next 2 hours
  • Achieve minimum 75% accuracy on test data
  • Create visualizations showing traffic patterns
  • Build a simple web interface for predictions

Dataset Structure

traffic_data.csv

Size: 1.8 GB | Records: 850,000

Historical traffic flow data from 500 intersections across the city

timestamp intersection_id vehicle_count avg_speed congestion_level

weather_data.csv

Size: 0.5 GB | Records: 175,000

Weather conditions affecting traffic patterns

timestamp temperature humidity precipitation visibility

events_data.json

Size: 0.2 GB | Records: 5,000

City events that impact traffic flow

event_id event_type start_time location impact_radius

Judging Criteria

How your project will be evaluated

Evaluation Process

Projects will be evaluated by a panel of industry experts and academic professionals. The judging process consists of automated testing, presentation evaluation, and code review.

Scoring Breakdown

Technical Implementation

40%
  • Algorithm correctness and efficiency
  • Code quality and organization
  • Model accuracy and performance
  • Appropriate use of tools and libraries

Innovation & Creativity

25%
  • Novel approach to the problem
  • Creative feature engineering
  • Unique insights from data analysis
  • Original visualization techniques

Presentation & Communication

20%
  • Clear explanation of approach
  • Effective demonstration
  • Quality of visualizations
  • Ability to answer questions

Documentation & Completeness

15%
  • Clear documentation and README
  • Complete submission requirements
  • Reproducible results
  • Professional presentation of work

Submission Requirements

Code Requirements

  • Complete source code with clear structure
  • Requirements.txt or equivalent dependency file
  • Working implementation that can be executed
  • Comments explaining key algorithms and decisions
  • Version control history (Git recommended)

Documentation Requirements

  • Comprehensive README.md file
  • Installation and setup instructions
  • Data preprocessing and feature engineering explanation
  • Model architecture and parameter choices
  • Results analysis and interpretation

Presentation Requirements

  • 5-minute live presentation
  • Demo of working solution
  • Key insights and findings
  • Challenges faced and solutions
  • Future improvements and extensions

Scoring Tips

  • Start with a simple working solution
