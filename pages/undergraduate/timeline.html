Submission Requirements

Code Repository

Complete implementation with proper documentation

  • Clean, well-documented codebase
  • Environment setup instructions
  • Docker containerization (bonus)
  • Unit tests and validation scripts
  • Performance benchmarking code

Technical Report

Comprehensive technical documentation (max 10 pages)

  • Problem analysis and approach
  • Data preprocessing methodology
  • Model architecture and fusion strategy
  • Experimental results and analysis
  • Limitations and future work

Demo Video

7-minute demonstration video

  • Live system demonstration
  • Technical architecture overview
  • User interface walkthrough
  • Performance metrics showcase
  • Team member introductions

Live Interface

Deployed web application for live evaluation

  • Functional web interface
  • Real-time prediction capability
  • Explainable AI features
  • Mobile-responsive design
  • API documentation
