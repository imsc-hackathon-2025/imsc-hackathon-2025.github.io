Track Overview

Challenge Focus

The undergraduate track focuses on real-world machine learning applications with moderate complexity. You'll work with larger datasets, implement more sophisticated algorithms, and develop end-to-end solutions.

  • Multi-modal data analysis
  • Deep learning implementations
  • Model optimization and deployment
  • Performance evaluation and validation

Recommended Tools

While you're free to use any tools, we recommend the following for the undergraduate track:

Python
TensorFlow
PyTorch
Scikit-learn
Pandas
Docker

Eligibility Requirements

  • Currently enrolled undergraduate student
  • Valid student ID required for verification
  • Basic programming experience (Python preferred)
  • Familiarity with machine learning concepts
  • Team of 2-4 members (all undergraduate level)
  • Available for the full 48-hour duration
