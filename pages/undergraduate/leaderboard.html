Advanced Submission Requirements

📄 Code Documentation

  • Submit well-commented source code
  • Include requirements.txt or environment.yml
  • Provide README with setup instructions
  • Document model architecture and parameters

🔬 Technical Report

  • 3-5 page technical summary required
  • Describe methodology and approach
  • Include experimental results and analysis
  • Discuss limitations and future work

⚡ Performance Requirements

  • Maximum inference time: 5 seconds per query
  • Model size limit: 2GB
  • Memory usage: Maximum 8GB RAM
  • Must run on provided evaluation platform

✨ Innovation Bonus

  • Novel approaches receive extra points
  • Creative feature engineering recognized
  • Ensemble methods encouraged
  • Transfer learning applications valued

Frequently Asked Questions

Can we use pre-trained models?

Yes, but you must fine-tune them on the provided dataset and clearly document your approach in the technical report.

Is external data allowed?

External data for pre-training is allowed, but you cannot use additional labeled data for the specific task.

How many team members are allowed?

Teams can have 1-4 undergraduate students. All members must be currently enrolled in undergraduate programs.

What programming languages are supported?

Any language is supported, but Python is recommended. Ensure your code can run on standard Linux environments.
