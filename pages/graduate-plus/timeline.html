Submission Requirements

Research Package

  • Complete source code repository
  • Comprehensive documentation
  • Dataset preprocessing scripts
  • Model training and evaluation code
  • Reproducibility instructions

Research Paper

  • 15-20 page technical paper
  • Abstract and introduction
  • Literature review
  • Methodology and results
  • Conclusion and future work

Presentation

  • 15-minute formal presentation
  • Academic conference format
  • Technical depth required
  • Q&A session (5 minutes)
  • Visual aids and demonstrations

Important Guidelines

Submission Deadline

All submissions must be completed by 1:00 PM on Sunday. Late submissions will not be accepted under any circumstances.

Code Requirements

All code must be original work created during the competition. Pre-existing libraries and frameworks are allowed.

Team Collaboration

Teams of 1-3 members only. External help beyond provided mentors is not permitted.

Computing Resources

High-performance computing clusters and GPU resources are available upon request for intensive computations.
