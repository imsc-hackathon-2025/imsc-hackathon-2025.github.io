Submission Guidelines

📝 Submission Format

  • Submit predictions as CSV file
  • Include team name and timestamp
  • Follow exact format specified in dataset
  • Maximum file size: 50MB

⏰ Submission Limits

  • Maximum 5 submissions per day
  • Only best score counts for ranking
  • Final submission deadline strictly enforced
  • Late submissions not accepted

✅ Validation Process

  • Automated validation upon submission
  • Instant feedback on format errors
  • Public leaderboard updated hourly
  • Final rankings based on private test set

🔒 Fair Play Policy

  • No sharing of solutions between teams
  • Original work only - no pre-trained models
  • External datasets not permitted
  • Violations result in disqualification
