Submission Requirements

Code Repository

Upload your complete solution to GitHub with clear documentation

  • Clean, commented code
  • Requirements.txt file
  • README with instructions
  • Demo scripts/notebooks

Presentation

5-minute video presentation explaining your solution

  • Problem understanding
  • Solution approach
  • Technical implementation
  • Results and insights

Results

Performance metrics and evaluation results

  • Model accuracy scores
  • Confusion matrices
  • Performance visualizations
  • Comparison with baselines

Fair Play

All submissions will be checked for plagiarism. Original work and proper attribution of external resources are required.
